Same Wi-Fi as your computer
Run the bridge on your computer in phone mode, then scan this code with your phone camera. Both devices must be on the same Wi-Fi network.
—
  1. On your computer run python zepp-bridge.py --lan and keep the window open.
  2. On your phone (same Wi-Fi) scan the code or open the address above.
  3. Sign in with your Zepp email + password — the bridge on your computer does the cloud call, so it works on the phone too.
No computer nearby?

Android: install Termux, then pkg install python and run python zepp-bridge.py on the phone itself; open http://127.0.0.1:8787 in the phone browser. iPhone: the cloud bridge needs a computer or server — instead export a .FIT file from your watch app and drop it in Session data above; it fills the card with no sign-in at all.
